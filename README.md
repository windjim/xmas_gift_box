# 聖誕節交換禮物抽籤系統

一個簡潔美觀的線上抽籤系統，專為聖誕節交換禮物活動設計。支援從 Excel 檔案匯入參與者資料，自動產生配對結果，確保不會抽到自己或產生互相配對的情況。

## 功能特色

- **Excel 檔案匯入**: 支援 `.xlsx` 和 `.xls` 格式的 Excel 檔案
- **智慧配對演算法**:
  - 使用 Fisher-Yates 洗牌演算法確保隨機性
  - 自動避免自己抽到自己
  - 避免互相配對（A→B 且 B→A）
  - 最多嘗試 1000 次以找到有效配對
- **資料驗證**:
  - 自動偵測並排除不完整的資料
  - 自動去除重複的參與者
  - 電話號碼自動格式化（0912-345-678）
- **使用者友善介面**:
  - 聖誕節主題設計
  - 雪花飄落動畫效果
  - 響應式設計，支援手機、平板、電腦
  - 即時訊息提示
  - 平滑的動畫效果
- **重新抽籤**: 支援一鍵重新抽籤功能

## 系統需求

- 現代瀏覽器（Chrome、Firefox、Safari、Edge 等）
- 支援 JavaScript
- 網路連線（用於載入 SheetJS 函式庫）

## 使用方式

### 1. 準備 Excel 檔案

您的 Excel 檔案需要包含以下欄位：

| 時間戳記 | 您的 IG 帳號 | 姓名 | 電話 | 7-11 店號+店名 |
|---------|------------|------|------|---------------|

#### 欄位說明

- **時間戳記**（選填）: 填表時間記錄
- **您的 IG 帳號**（必填）: Instagram 帳號
- **姓名**（必填）: 參與者姓名
- **電話**（必填）: 聯絡電話（10碼）
- **7-11 店號+店名**（必填）: 取貨門市資訊

#### 範例資料

```
時間戳記              您的 IG 帳號    姓名      電話          7-11 店號+店名
2024/12/01 10:30     @alice_wang    王小明    0912345678    266479-城林門市
2024/12/01 10:35     @bob_lee       李小華    0923456789    123456-中山門市
2024/12/01 10:40     @charlie_chen  陳大同    0934567890    789012-信義門市
```

詳細的 Excel 格式說明請參考 [Excel 範例說明](.AI/Excel範例說明.md)。

### 2. 開啟系統

直接開啟 [index.html](index.html) 檔案即可使用。

或使用本地伺服器：

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js
npx http-server

# 然後在瀏覽器開啟
http://localhost:8000
```

### 3. 上傳 Excel 檔案

1. 點擊「選擇 Excel 檔案」按鈕
2. 選擇您準備好的 Excel 檔案
3. 系統會自動驗證並顯示參與者人數

### 4. 開始抽籤

1. 確認參與者人數正確
2. 點擊「開始抽籤」按鈕
3. 查看配對結果

### 5. 重新抽籤（可選）

如果對結果不滿意，可點擊「重新抽籤」按鈕重新配對。

### 核心演算法

#### Fisher-Yates 洗牌演算法

```javascript
function shuffleArray(array) {
    const shuffled = [...array];
    for (let i = shuffled.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
    }
    return shuffled;
}
```

1. 檢查是否有人抽到自己

3. 最多嘗試 1000 次以找到有效配對

## 注意事項

### 資料要求

- **最少人數**: 2 人（會顯示警告訊息）
- **建議人數**: 3 人以上（避免互相配對）
- **必填欄位**: IG 帳號、姓名、電話、7-11 店鋪

### 資料處理

- 不完整的資料會被自動排除並顯示警告
- 重複的資料會被自動去除（依據：姓名 + IG + 電話）
- 電話號碼會自動格式化為 `0912-345-678` 格式

### 瀏覽器相容性

- Firefox 55+
- Safari 11+
- Edge 79+

## 常見問題

### Q1: 上傳檔案後沒有反應？
**A**: 請確認：
- 檔案格式為 `.xlsx` 或 `.xls`
- Excel 檔案包含必要欄位
- 至少有一筆完整的資料

### Q2: 顯示「資料不完整」？
**A**: 請檢查 Excel 檔案，確保每筆資料都填寫了：
- IG 帳號
- 姓名
- 電話
- 7-11 店號+店名

（時間戳記可以為空）

### Q3: 只有 2 個人可以抽籤嗎？
**A**: 可以，但系統會顯示警告訊息，因為 2 人一定會互相配對。建議至少 3 人參加。

### Q4: 抽籤結果可以匯出嗎？
**A**: 目前版本不支援匯出功能。您可以：
- 截圖儲存結果
- 使用瀏覽器的列印功能（Ctrl+P / Cmd+P）儲存為 PDF

### Q5: 手機可以使用嗎？
**A**: 可以！本系統採用響應式設計，完美支援手機、平板和電腦。
