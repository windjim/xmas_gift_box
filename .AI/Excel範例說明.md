# Excel 檔案格式說明

## 必要欄位

您的 Excel 檔案需要包含以下欄位（標題列）：

| 時間戳記 | 您的 IG 帳號 | 姓名 | 電話 | 7-11 店號+店名 |
|---------|------------|------|------|---------------|

## 欄位說明

### 1. 時間戳記（選填）
- **必要性**: 選填（可以為空）
- **格式**: 任意時間格式
- **範例**: `2024/12/01 10:30:00`
- **說明**: 此欄位不會顯示在抽籤結果中，僅用於記錄填表時間

### 2. 您的 IG 帳號（必填）
- **必要性**: 必填
- **格式**: IG 帳號名稱
- **範例**: `@alice_ig` 或 `alice_ig`
- **說明**: 參與者的 Instagram 帳號

### 3. 姓名（必填）
- **必要性**: 必填
- **格式**: 中文或英文姓名
- **範例**: `王小明`、`Alice Wang`
- **說明**: 參與者的姓名

### 4. 電話（必填）
- **必要性**: 必填
- **格式**: 手機號碼（10碼）
- **範例**: `0912345678`、`0912-345-678`
- **說明**: 參與者的聯絡電話，系統會自動格式化為 `0912-345-678` 格式

### 5. 7-11 店號+店名（必填）
- **必要性**: 必填
- **格式**: `店號-店名`
- **範例**: `266479-城林門市`
- **說明**: 參與者指定的 7-11 取貨門市

## 建立測試檔案步驟

### 方法 1: 使用 Excel
1. 開啟 Microsoft Excel 或 Google Sheets
2. 在第一列輸入欄位名稱（如上表）
3. 從第二列開始輸入參與者資料
4. 儲存為 `.xlsx` 格式

### 方法 2: 使用 Google 表單
1. 建立 Google 表單，包含以下問題：
   - IG 帳號（簡答）
   - 姓名（簡答）
   - 電話（簡答）
   - 7-11 店號+店名（簡答）
2. 收集回應後，在「回應」頁籤點選 Excel 圖示
3. 下載為 Excel 檔案

## 注意事項

### ✅ 正確的資料
```
姓名: 王小明
IG: @alice_wang
電話: 0912345678
店鋪: 266479-城林門市
```

### ❌ 不完整的資料（會被系統排除）
```
姓名: 王小明
IG:
電話: 0912345678
店鋪: 266479-城林門市
```
➡️ 系統會提示：「王小明資料不完整，因此不進行配對」

### ⚠️ 重複的資料（系統會自動去除）
如果有兩筆資料的「姓名 + IG 帳號 + 電話」完全相同：
```
第1筆: 王小明, @alice_wang, 0912345678
第2筆: 王小明, @alice_wang, 0912345678
```
➡️ 系統會提示：「偵測到重複資料: 王小明，已自動去除重複」

### ⚠️ 人數限制
- **最少 2 人**: 可以抽籤，但會出現警告訊息
- **建議 3 人以上**: 才能確保不會互相配對

## 欄位名稱變化支援

系統支援以下欄位名稱變化：

| 標準名稱 | 可接受的變化 |
|---------|------------|
| 您的 IG 帳號 | `IG帳號`, `IG` |
| 姓名 | `name` |
| 電話 | `phone` |
| 7-11 店號+店名 | `店號+店名`, `7-11` |

這讓您有更大的彈性來命名欄位！
